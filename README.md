## 📖 Overview

A simple whiteboard app where you draw freehand and share with friends. Built with SolidJS and perfect-freehand for smooth stroke rendering.

## 🏗 Project structure

```
whiteboard/
├── src/          # SolidJS components
├── public/
└── vite.config.ts
```

## 🛠 Tech stack

`SolidJS` · `perfect-freehand` · `Tailwind` · `Vite`

## 📦 Quick start

```bash
git clone https://github.com/m3rashid/whiteboard.git
cd whiteboard
yarn install
yarn dev
```
